# Selected code and data for Mean-filed approximation and Monte Carlo simulations

This repository contains the code and data used in our study of Non-homophilic interactions and phase transitions in opinion dynamics.

The Monte Carlo and mean-field analyses are presented in six Jupyter notebooks in `notebooks/`. The source Python code is provided in `src/`, and precomputed data used for the 42-bin mean-field figures are provided in `data/`.

Python 3.9 or later is recommended. Install the required packages with `python -m pip install -r requirements.txt`, then run the notebooks from top to bottom in JupyterLab or VS Code.
